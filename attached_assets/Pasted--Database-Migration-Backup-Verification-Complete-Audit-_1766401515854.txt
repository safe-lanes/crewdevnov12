# Database Migration & Backup Verification - Complete Audit

## Objective
Verify that all database schema changes have proper migrations, auto-migration is working, and create a fresh backup of the current database state.

## Tasks to Execute

### TASK 1: Migration Files Audit
Run these commands and show me the output:
```bash
# List all migration files with timestamps
ls -lh migrations/
ls -lh drizzle/ 2>/dev/null || echo "No drizzle folder found"

# Count total migration files
find . -name "*.sql" -path "*/migrations/*" -o -name "*migration*.ts" | wc -l

# Show the 10 most recent migration files
find . -name "*.sql" -path "*/migrations/*" -o -name "*migration*.ts" -exec ls -lt {} + | head -20
```

### TASK 2: Check Auto-Migration Configuration
Show me:
```bash
# Check package.json scripts section
cat package.json | grep -A 10 '"scripts"'

# Check if drizzle config exists
cat drizzle.config.ts 2>/dev/null || echo "No drizzle.config.ts found"

# Check server startup for migration execution
cat server/index.ts | grep -i -A 5 -B 5 migrate

# Check for any migration runner scripts
cat server/db/migrate.ts 2>/dev/null || echo "No migrate.ts found"
```

### TASK 3: Current Database Schema Analysis
Run these SQL queries:
```bash
# Get current table count and list
psql "$DATABASE_URL" -c "SELECT COUNT(*) as total_tables FROM information_schema.tables WHERE table_schema = 'public';"

# List all current tables
psql "$DATABASE_URL" -c "SELECT tablename FROM pg_catalog.pg_tables WHERE schemaname = 'public' ORDER BY tablename;"

# Check last migration applied
psql "$DATABASE_URL" -c "SELECT * FROM drizzle.__drizzle_migrations ORDER BY created_at DESC LIMIT 5;" 2>/dev/null || echo "No migration tracking table found"
```

### TASK 4: Create Fresh Backup
Execute backup and verify:
```bash
# Create new backup with today's date
npx tsx server/backup-database.ts

# List all backups with sizes
ls -lh backups/

# Get table count from the newest backup
LATEST_BACKUP=$(ls -t backups/*.sql | head -1)
echo "Latest backup: $LATEST_BACKUP"
grep -c "CREATE TABLE" "$LATEST_BACKUP"
grep -c "COPY public" "$LATEST_BACKUP"

# Show backup file size
du -h "$LATEST_BACKUP"
```

### TASK 5: Detect Schema Changes
Check for any unmigrated changes:
```bash
# If using Drizzle Kit, check for pending changes
npx drizzle-kit generate 2>/dev/null || echo "Drizzle Kit not configured"

# Compare current table count with backup documentation (was 32 tables on Nov 14)
psql "$DATABASE_URL" -c "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema = 'public';"
```

3. **Database State:**

   - Last migration applied timestamp

4. **Fresh Backup:**
   - New backup filename and size
   - Table count in backup
   - Confirmation backup was successful

5. **Changes Detected:**

## If Issues Found

If you detect any of these issues, please notify me:
- ⚠️ Schema changes without corresponding migration files
- ⚠️ Auto-migration not configured to run on startup
- ⚠️ Backup script failed or incomplete
- ⚠️ Table count mismatch or missing tables
- ⚠️ Migration tracking table not found

Please execute all tasks above and provide a comprehensive report with all command outputs.
