```sql
    vessel_id text NOT NULL,
    rank text NOT NULL,
    name text NOT NULL,

    opa_mode boolean DEFAULT false,
    created_at timestamp without time zone DEFAULT now(),
    updated_at timestamp without time zone DEFAULT now(),
    CONSTRAINT rest_hours_daily_records_pkey PRIMARY KEY (id)
);
```

- `month_year` field suggests this table stores monthly records, not daily
- `daily_records` is a text field (likely JSON) containing the actual daily data
- Multiple fields: crew_member_id, vessel_id, month_year that might define uniqueness
