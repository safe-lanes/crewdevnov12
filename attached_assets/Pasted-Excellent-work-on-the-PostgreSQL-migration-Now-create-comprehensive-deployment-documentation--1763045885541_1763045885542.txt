## 1. LOCAL DEVELOPMENT SETUP

### Prerequisites:
- Node.js version required (18+)
- PostgreSQL version required (14+)
- npm/yarn version
- System requirements

### Step-by-Step Local Setup:

#### **For Windows:**

**Install PostgreSQL:**
1. Download PostgreSQL from https://www.postgresql.org/download/windows/
2. Run installer (PostgreSQL 15 recommended)
3. During installation:
   - Set password for postgres user
   - Port: 5432 (default)
   - Install pgAdmin 4 (GUI tool)
4. Add PostgreSQL to PATH:
```cmd
   setx PATH "%PATH%;C:\Program Files\PostgreSQL\15\bin"
```

**Setup Project:**
```cmd
# Clone repository
git clone <your-repo>
cd <project>

# Install dependencies
npm install

# Create .env file (use .env.example as template)
copy .env.example .env

# Edit .env with Notepad or VS Code
notepad .env
```

**Configure Environment Variables (.env for Windows):**
```env
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/crew_management
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=crew_management
NODE_ENV=development
PORT=5000
```

**Create Database (Windows Command Prompt or PowerShell):**
```cmd
# Using psql command
psql -U postgres

# In psql prompt:
CREATE DATABASE crew_management;
\q

# OR use pgAdmin GUI:
# 1. Open pgAdmin 4
# 2. Right-click Databases → Create → Database
# 3. Name: crew_management
# 4. Click Save
```

**Run Migrations (Windows):**
```cmd
# Generate migrations
npm run db:generate

# Apply migrations
npm run db:push

# Optional: Migrate existing data
npx tsx server/migrate-json-to-postgres.ts
```

**Start Development Server (Windows):**
```cmd
# Development mode with hot reload
npm run dev

# OR production build
npm run build
npm start
```

**Access Application:**
- Open browser: http://localhost:5000

### Troubleshooting Local Setup:

**Windows Issues:**

**Issue:** "psql is not recognized"
```cmd
# Add to PATH manually
set PATH=%PATH%;C:\Program Files\PostgreSQL\15\bin

# Or permanently via System Properties:
# 1. Search "Environment Variables" in Start Menu
# 2. Edit System PATH
# 3. Add: C:\Program Files\PostgreSQL\15\bin
```

**Issue:** "Connection refused" on Windows
```cmd
# Check PostgreSQL is running
sc query postgresql-x64-15

# Start if stopped
net start postgresql-x64-15

# Check port
netstat -an | findstr 5432
```

**Issue:** "Permission denied" on Windows
- Run Command Prompt or PowerShell as Administrator
- Check PostgreSQL service is running
- Verify firewall allows port 5432

**Linux/Mac Issues:**

**Issue:** "Connection refused" on Linux
```bash
# Check PostgreSQL is running
sudo systemctl status postgresql

# Start if stopped
sudo systemctl start postgresql

# Check port
sudo netstat -tulpn | grep 5432
```

**Issue:** "Peer authentication failed"
```bash
# Edit pg_hba.conf
sudo nano /etc/postgresql/15/main/pg_hba.conf

# Change from:
local   all   postgres   peer

# To:
local   all   postgres   md5

# Restart PostgreSQL
sudo systemctl restart postgresql
```

## 3. PRODUCTION DEPLOYMENT

### Windows Server Deployment:

**Option A: Windows Server with IIS**

**Prerequisites:**
- Windows Server 2019/2022
- IIS installed
- Node.js installed
- PostgreSQL installed or use cloud database

**Setup:**
```cmd
# Install iisnode module
# Download from: https://github.com/Azure/iisnode

# Install PM2 for Windows
npm install -g pm2
npm install -g pm2-windows-service

# Setup PM2 as Windows Service
pm2-service-install
pm2 start npm --name "crew-management" -- start
pm2 save
```

**IIS Configuration:**
1. Open IIS Manager
2. Add Website
3. Point to application folder
4. Configure Application Pool (Node.js)
5. Install URL Rewrite module
6. Configure web.config for Node.js

**web.config for IIS:**
```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <system.webServer>
    <handlers>
      <add name="iisnode" path="server/index.js" verb="*" modules="iisnode"/>
    </handlers>
    <rewrite>
      <rules>
        <rule name="NodeInspector" patternSyntax="ECMAScript" stopProcessing="true">
          <match url="^server/index.js\/debug[\/]?" />
        </rule>
        <rule name="StaticContent">
          <action type="Rewrite" url="public{REQUEST_URI}"/>
        </rule>
        <rule name="DynamicContent">
          <conditions>
            <add input="{REQUEST_FILENAME}" matchType="IsFile" negate="True"/>
          </conditions>
          <action type="Rewrite" url="server/index.js"/>
        </rule>
      </rules>
    </rewrite>
  </system.webServer>
</configuration>
```

**Option B: Windows with PM2**
```cmd
# Install PM2 globally
npm install -g pm2

# Start application
pm2 start npm --name crew-management -- start

# Configure to run on Windows startup
pm2 startup
pm2 save

# Monitor application
pm2 monit

# View logs
pm2 logs crew-management
```

### Linux Server Deployment:

**Option A: Ubuntu/Debian with systemd**

**Create systemd service:**
```bash
# Create service file
sudo nano /etc/systemd/system/crew-management.service
```

**Service configuration:**
```ini
[Unit]
Description=Crew Management System
After=network.target postgresql.service

[Service]
Type=simple
User=nodeuser
WorkingDirectory=/var/www/crew-management
Environment=NODE_ENV=production
Environment=DATABASE_URL=postgresql://...
ExecStart=/usr/bin/npm start
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

**Enable and start:**
```bash
sudo systemctl daemon-reload
sudo systemctl enable crew-management
sudo systemctl start crew-management
sudo systemctl status crew-management
```

**Option B: Linux with PM2**
```bash
# Install PM2
npm install -g pm2

# Start application
pm2 start npm --name crew-management -- start

# Configure startup
pm2 startup systemd
pm2 save

# Monitor
pm2 monit
```

### Docker Deployment (Cross-Platform):

**Works on: Windows, Linux, Mac**

**Dockerfile:**
```dockerfile
FROM node:18-alpine

WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm ci --only=production

# Copy application code
COPY . .

# Build application
RUN npm run build

# Expose port
EXPOSE 5000

# Start application
CMD ["npm", "start"]
```

**docker-compose.yml:**
```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "5000:5000"
    environment:
      - DATABASE_URL=postgresql://postgres:password@db:5432/crew_prod
      - NODE_ENV=production
    depends_on:
      - db
    restart: unless-stopped

  db:
    image: postgres:15-alpine
    volumes:
      - postgres_data:/var/lib/postgresql/data
    environment:
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=crew_prod
    restart: unless-stopped

volumes:
  postgres_data:
```

**Run with Docker (Any Platform):**
```bash
# Build and start
docker-compose up -d

# View logs
docker-compose logs -f app

# Stop
docker-compose down
```

## 4. DATABASE MAINTENANCE

### Backup Strategy:

**Windows:**
```cmd
# Manual backup
pg_dump -U postgres -h localhost -p 5432 crew_management > backup_%date:~-4,4%%date:~-10,2%%date:~-7,2%.sql

# Automated backup (Task Scheduler)
# Create batch file: backup.bat
@echo off
set PGPASSWORD=your_password
pg_dump -U postgres crew_management > C:\backups\crew_%date:~-4,4%%date:~-10,2%%date:~-7,2%.sql

# Schedule in Task Scheduler:
# 1. Open Task Scheduler
# 2. Create Basic Task
# 3. Trigger: Daily at 2:00 AM
# 4. Action: Start Program
# 5. Program: C:\backups\backup.bat
```

**Linux/Mac:**
```bash
# Manual backup
pg_dump crew_management > backup_$(date +%Y%m%d).sql

# Automated backup (cron)
crontab -e

# Add this line (runs daily at 2 AM):
0 2 * * * pg_dump crew_management > /backups/crew_$(date +\%Y\%m\%d).sql
```

**Restore from Backup (Any Platform):**
```bash
# Windows
psql -U postgres crew_management < backup_20250113.sql

# Linux/Mac
psql crew_management < backup_20250113.sql
```

## 6. FIREWALL CONFIGURATION

### Windows Firewall:
```cmd
# Allow Node.js app
netsh advfirewall firewall add rule name="Crew Management" dir=in action=allow protocol=TCP localport=5000

# Allow PostgreSQL
netsh advfirewall firewall add rule name="PostgreSQL" dir=in action=allow protocol=TCP localport=5432
```

### Linux Firewall (UFW):
```bash
# Allow Node.js app
sudo ufw allow 5000/tcp

# Allow PostgreSQL
sudo ufw allow 5432/tcp

# Enable firewall
sudo ufw enable
```
