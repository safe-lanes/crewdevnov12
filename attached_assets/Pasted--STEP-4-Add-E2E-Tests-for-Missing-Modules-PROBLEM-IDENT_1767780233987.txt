## SPECIAL INSTRUCTIONS:

### Module Detection:
1. **Check if navigation exists** before clicking
2. **Use test.skip()** if module doesn't exist
3. **Verify URL** after navigation
4. **Use defensive selectors** - multiple fallbacks

### Defensive Testing Pattern:
```typescript
// Always check count before expecting
const element = page.locator('selector');
if (await element.count() > 0) {
  await expect(element).toBeVisible();
} else {
  // Fallback or skip
  test.skip();
}
```

### Empty State Handling:
```typescript
// Don't assume data exists
const rows = page.locator('table tbody tr');
const rowCount = await rows.count();

if (rowCount > 0) {
  // Test with data
} else {
  // Test empty state
  const emptyMessage = page.locator('.empty-state, text=/no data/i');
  // Should show something
}
```
