## Test Categories

### 1. API Endpoint Tests

Test each endpoint with curl or HTTP client:

```bash
# Base URL
BASE=http://localhost:5000/api/v2/crew-pool

# ============================================
# CREW MEMBERS
# ============================================

# List all crew
curl $BASE/crew

# Create crew
curl -X POST $BASE/crew \
  -H "Content-Type: application/json" \
  -d '{
    "empNo": "EMP001",
    "firstName": "John",
    "familyName": "Doe",
    "status": "active"
  }'

# Get by UUID
curl $BASE/crew/{crewUuid}

# Update
curl -X PATCH $BASE/crew/{crewUuid} \
  -H "Content-Type: application/json" \
  -d '{"presentRank": "Captain"}'

# Delete (soft)
curl -X DELETE $BASE/crew/{crewUuid}

# ============================================
# DOCUMENTS
# ============================================

# List documents
curl $BASE/crew/{crewUuid}/documents

# Create document
curl -X POST $BASE/crew/{crewUuid}/documents \
  -H "Content-Type: application/json" \
  -d '{
    "documentType": "Passport",
    "documentNumber": "AB123456",
    "issueDate": "2024-01-01",
    "expiryDate": "2034-01-01"
  }'

# Update document
curl -X PATCH $BASE/crew/{crewUuid}/documents/{docUuid} \
  -H "Content-Type: application/json" \
  -d '{"expiryDate": "2035-01-01"}'

# Delete document
curl -X DELETE $BASE/crew/{crewUuid}/documents/{docUuid}

# ============================================
# Repeat for all sections...
# ============================================
```

### 2. Expected Response Validation

| Endpoint | Expected Response |
|----------|-------------------|
| `GET /crew` | Array of crew members |
| `POST /crew` | Created crew with `crewUuid` |
| `GET /crew/:uuid` | Single crew object |
| `PATCH /crew/:uuid` | Updated crew object |
| `DELETE /crew/:uuid` | 204 No Content |
| `GET /crew/:uuid/documents` | Array with nested `attachments` |

### 3. Error Case Testing

```bash
# 404 - Crew not found
curl $BASE/crew/nonexistent-uuid
# Expected: {"error": "Crew member not found: nonexistent-uuid"}

# 400 - Validation error
curl -X POST $BASE/crew \
  -H "Content-Type: application/json" \
  -d '{}'
# Expected: {"error": "Validation failed", "details": [...]}

# 400 - Invalid data
curl -X POST $BASE/crew \
  -H "Content-Type: application/json" \
  -d '{"empNo": "", "firstName": "John", "familyName": "Doe"}'
# Expected: Validation error for empNo
```
