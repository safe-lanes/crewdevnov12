## Phase 4: Version Toggle

### 4.1 Toggle Hook
**File:** `client/src/modules/rest-hours/hooks/useRestHoursVersion.ts`
```typescript
export function useRestHoursVersion() {
  const [version, setVersion] = useState<'v1' | 'v2'>(() => {
    return localStorage.getItem('rest-hours-version') as 'v1' | 'v2' || 'v1';
  });
  
  const toggleVersion = () => {
    const newVersion = version === 'v1' ? 'v2' : 'v1';
    localStorage.setItem('rest-hours-version', newVersion);
    setVersion(newVersion);
  };
  
  return { version, toggleVersion, isV2: version === 'v2' };
}
```

## Key Principles

1. **EXACT V1 Logic Copy** - All business logic from V1 APIs copied to V2
2. **UUID-based Routing** - Use UUIDs instead of integer IDs for API routes
3. **Audit User Tracking** - Apply `createdByUuid`/`updatedByUuid` in service layer
4. **Soft Deletes Only** - Set `isDeleted=true`, never hard delete
5. **Same UI** - V2 frontend looks exactly like V1
