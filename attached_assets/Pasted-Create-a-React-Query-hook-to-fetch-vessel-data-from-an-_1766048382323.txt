Create a React Query hook to fetch vessel data from an external API endpoint.

TASK: Create a new file at client/src/hooks/useExternalVessels.ts

PURPOSE: This hook will fetch vessel master data from our external SAIL ERP API to populate vessel type dropdowns/selectors in the application.

REQUIREMENTS:

1. Install dependencies (if not already present):
   - @tanstack/react-query
   - @testing-library/react-hooks (for testing)

2. Implement the hook with these specifications:
   - Hook name: useExternalVessels
   - Use React Query's useQuery hook
   - Query configuration:
     * queryKey: ['external-vessels']
     * staleTime: 5 * 60 * 1000 (5 minutes)
     * retry: 2
     * enabled: true (auto-fetch on mount)

3. API endpoint details:
   - Base URL: https://dev.sl-sail.com/b/api/v1/crewmasterdata/getallmasterdata/vessels
   - Query parameter: domain (dynamically retrieved)
   - Method: GET
   - Headers: { 'accept': '*/*' }

4. Domain retrieval logic:
   - Read 'domain' from localStorage
   - Fallback to 'rsms' if not found
   - Example: const domain = localStorage.getItem('domain') || 'rsms';

5. Error handling:
   - Check response.ok before parsing
   - Throw descriptive error if fetch fails
   - Return parsed JSON on success

6. TypeScript types:
   - Define a Vessel interface with at least: id, name, vesselType
   - Add proper return type for the hook

EXAMPLE USAGE:
```typescript
// In a component
const { data: vessels, isLoading, error } = useExternalVessels();
```

EXPECTED RESPONSE FORMAT:
The API returns an array of vessel objects. Ensure the hook properly types this response.
