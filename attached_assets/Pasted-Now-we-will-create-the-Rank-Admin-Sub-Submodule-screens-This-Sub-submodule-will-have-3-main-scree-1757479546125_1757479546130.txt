Now we will create the Rank Admin Sub Submodule screens. 
This Sub submodule will have 3 main screens navigable through tab switcher (See image) with following options:

Rank Master || Company || Vessel

The main functionality of this Rank admin and the connection between the above 3 tabs is briefly described below (I will provide detailed instruction to create screen in each tab separately). 

You can consider these as a stepper going from Rank Master to Company and then to Vessel. Without Rank Master, the user cannot create Company and without Company, user cannot create Vessel. 

•	This configuration will typically be done when the company/client starts using this module for the first time, so it needs to configure all the Seafarer ranks that it uses in the company (There can be slight difference in the way the ranks are used between different companies/ clients so this is where it will be configured,  including what they call them as one company may call chief officer whereas another company may call same officer 1st Officer).
•	The initial information in the first tab ‘Rank master’ will typically be pre-populated by the SAIL Admin (This is important as we want to maintain a consistency in the way that the basic ranks are used by different Companies.) While Company would be free to name the ranks as per their company requirement, we want to maintain a basic Rank Id Master e.g., Chief Officer ID is S002, now one company may name it Chief Officer and another may name it 1st Officer (But both will have a common SAIL Rank Id). This will also be helpful if need to create a general Industry intelligence across multiple companies which can eventually help everyone. 
•	Once the Ranks are populated in ‘Rank Master’, Company can select which of these ranks are applicable to their fleet (simple tick will filter Company specific Ranks). They also have the option to rename these ranks. 
•	The shortlisted Ranks will automatically show up in the ‘Company Tab’. Here the Company can further fine tune Company specific ranks 
e.g., if the company generally employs two third officers on certain ships they can create two 3rd officers in the master list which then can be further filtered for specific vessels in the ‘Vessels’ Tab.  
Basically, the Company can configure manning of entire fleet in ‘Company Tab’ if it is uniform, or go to ‘Vessels’ Tab for configuring individual vessels or a group of them.  

•	In addition to the initial configuration (While setting up Company) additional configuration would be required whenever Company:
o	Adds new vessels or vessel types.
o	Decides to change manning levels due to changing conditions or routine review/ feedback.
o	New ranks are introduced etc.
