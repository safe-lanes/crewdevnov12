Now create the ‘Vessel Tab’ screen as per the attached image.

The number of rows in the vessel tab will follow exactly the same as in Company Tab. So if Company tab shows 3rd Off_1, 3rd Off_2 , the Vessel tab will show the same. Even any subsequent change in the ‘Company Tab’ (e.g., adding 3rd Off_3) will automatically add a new row in ‘Vessel’ Tab.

In the ‘Vessel’ Tab then the user can individually select applicable seafarers in each vessel or a group of vessels by clicking on the ‘Actual Manning’ column. 

Analogy: 
1.	To give an analogy consider ‘ranks’ in the ‘Company’ Tab as all the ‘subjects’ being offered for a grade in a ‘school’ and in the ‘vessels’ can be compared to ‘students’. 
2.	Now from the dropdown list you can select any student/vessel and tick mark which subjects apply to him. So it can be equal to or less than the existing list. 
3.	Now assume the school/company starts offering a new subject/rank, so it will enter a new subject/rank in the  School/‘Company’ tab. As soon as it is saved, the new subject/rank will start showing in the Student/ ‘Vessel’ tab also for their selection. As a result this function can capture the subjects/ranks assigned to each student/ vessel. 
4.	Now there can be many  students/ vessels so selecting each student/vessel from the dropdown and clicking applicable subjects/ ranks can be tedious, so there is a functionality given where the user can create student/ vessel groups using the (+) icon next to student/ ‘vessel’ filter dropdown. On clicking this icon a popup opens which lists all the students/ vessels. User can create a new group, assign a new name and select e.g., 10 students/ vessels to be part of this group. Now from the dropdown user can select this group and make selections as a group which will be applicable to each individual student/ vessel. 
Note-  If a group is selected from the dropdown:
-	Only those columns will be visible where the values for all students/vessels in the group are same. If the values are different then the user will have to go to individual students/vessels and revise. So by default for the initial setup (R1) all columns will be visible.  
5.	There will also be cases where a student/ vessel needs to change a subject/ rank. For this a ‘+ Revision’ button is given on Top right and two filters ‘Revision No’ and ‘Revision Date’ in the filters bar so that every change is recorded with a revision no and revision date it is applicable from. When user clicks  ‘+ Revision’ button the ‘Revision No’ filter automatically jumps to ‘last revision no + 1’. 
o	Note1: When the data is being entered for the first time the revision no will be 1. The revision date can be manually entered by the user.  
o	The ‘Save Draft’, ‘Submit’ & ‘Cancel’ buttons will only appear if in ‘Revision’ mode, i.e., the change has not been Submitted.
