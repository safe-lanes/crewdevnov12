# Correction Request: Candidate to Crew Pool Transfer Implementation Plan

## Issue Summary

After reviewing your implementation plan against the actual codebase, we found critical schema discrepancies. The SQL migration files and TypeScript schemas have DIFFERENT column names. Since Drizzle ORM uses TypeScript schemas at runtime, we must use TypeScript field names.

## Critical Corrections Needed

Your mapping used SQL column names. Here are the corrections:

### 2. REMOVE NAME SPLITTING LOGIC - NOT NEEDED

Your plan said: "name → split into first/middle/family_name"

This is WRONG. The TypeScript schemas ALREADY have split fields on BOTH recruitment and crew sides:

**cand_family_info (TypeScript):**
- spouseFirstName, spouseMiddleName, spouseFamilyName (already split)
- numDependentChildren, fatherName, motherName (already exist)

**cand_children (TypeScript):**
- firstName, middleName, familyName (already split, NOT single "name" field)

**cand_next_of_kin (TypeScript):**
- firstName, middleName, familyName (already split)
- telephone, email (separate fields, NOT "contact_number")

**Correction:** Direct 1:1 mapping, no splitting required.
